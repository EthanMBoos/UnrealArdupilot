# Version 1 acceptance

Version 1 is one reproducible, air-started Aerosonde experiment that can be inspected headlessly,
run through Chaos in Unreal, controlled by a pinned ArduPlane SITL container, and replayed from its
saved evidence. Boat dynamics, PX4, sensor errors, takeoff and landing, and flight-data calibration
are later work.

## Proven now

- The aircraft and run schemas reject unknown fields, duplicate keys, unsupported versions,
  nonfinite values, incomplete channel maps, invalid schedules, and out-of-range controls.
- The shared C++ model builds with warnings as errors on macOS. Unit tests cover the
  force equations, rigid-body equations, ISA atmosphere, command mapping, limits, and low-speed and
  high-angle finite behavior.
- Trim, linearization, scripted simulation, comparison, timestep convergence, and deterministic
  replay use the same aircraft code. Headless replay is byte-identical.
- The offline JSBSim comparison checks aerodynamic force and moment trends over a saved grid. It is
  reference-model agreement, not physical validation.
- The pinned ArduPlane container and live integration probe implement checks for Docker-to-host UDP,
  consecutive frame counts, controller-rate transition, sensor replies, and JSON-backend startup.

## Demonstrated locally

- UE 5.8.1 compiles the plugin on macOS with Xcode 26.6. The scripted `uvd unreal` smoke case ran
  720 Chaos intervals at 120 Hz, applied 720 model wrenches, exited automatically, and saved a
  finite-state report and engine log.
- This is an exploratory open-loop smoke result. It proves that the current host, plugin lifecycle,
  physics-thread API, run loading, and basic evidence path work together; it is not G0, U0, or U1.

## Implemented but not yet accepted

- The Unreal plugin compiles the same core sources, configures Chaos mass and inertia,
  reads the authored run and aircraft files, initializes the body state, performs the NED/FRD and
  Unreal unit conversions directly, evaluates one model wrench per async physics tick, and applies
  that wrench once.
- `uvd unreal` validates a controller-free scripted run, checks the local UE host, launches the real
  editor process, captures its log, waits for the configured final tick, and checks the report.
- `uvd sitl` implements process launch and cleanup scaffolding, but the Unreal plugin does not yet
  implement the ArduPilot JSON/UDP session. It must not be described as closed-loop flight yet.
- Self-hosted macOS and Linux Unreal build jobs still need to be added once the acceptance probes
  exist. Licensed engine installations cannot run on ordinary GitHub-hosted workers.

These items are not called proven until the G0/U0-U3 experiments below produce saved passing
reports on both host platforms.

## Release gates

| Gate | Evidence required |
|---|---|
| G0 geospatial placement | Spawned LLA and heading agree with the run file; North/East and MSL/ellipsoid conversions pass; enabling Cesium does not change the model wrench. |
| U0 Chaos mechanics | Unit acceleration, angular acceleration, center-of-mass, inertia, fixed-step, render-rate, render-hitch, and delayed-command probes pass at 60, 120, and 240 Hz. |
| U1 open loop | Matched states produce the same wrench in CMake and Unreal; Chaos and RK4 trajectories converge under timestep refinement. |
| U2 transport | Every accepted unique PWM frame maps to exactly one committed interval; duplicates resend without advancing; gaps, stale frames, malformed packets, and timeouts fail explicitly. |
| U3 closed loop | Warm-up and release criteria pass; ArduPlane flies the prescribed FBWA case; controller logs and packet traces are complete; cross-backend replay passes. |
| Platforms | The same pinned experiment and tolerances pass on current macOS and Linux Unreal hosts. |

A solid proven v1 means all six gates pass from a clean commit with the tested versions recorded in
the evidence manifests. A passing headless suite or a visually plausible Unreal flight alone is not
enough.

## Release command sequence

```sh
mkdir build && cd build
cmake .. && make
cd ..
ctest --test-dir build --output-on-failure
uv sync --locked
uv run --locked python verification/jsbsim_compare.py --samples 10000
uv run --locked python verification/timestep_convergence.py
build/uvd unreal examples/runs/unreal_smoke.json --preflight
build/uvd unreal examples/runs/unreal_smoke.json
python3 ardupilot/transport_probe.py --frames 50
build/uvd sitl examples/runs/unreal_ardupilot.json --preflight
build/uvd sitl examples/runs/unreal_ardupilot.json
```
